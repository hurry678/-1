# 第一问详细实施计划

## 1. 完成目标

针对附件 5 的 32 项静态任务，在 20 辆 OHT、152 条有向 Link、36 个 Port 以及 33 个弯轨独占组和 21 个汇流控制对象上，完成任务分配、车内排序、空载路径、载货路径、取放货、交通冲突控制和逐步运动仿真。

最终候选方案必须同时满足：

1. 32 项任务全部完成，每项任务只由一辆 OHT 执行；
2. Link 方向、Port 实际偏移、逐 Link 限速全部使用附件数据；
3. 加速度不超过 2000 mm/s²，减速度绝对值不超过 3000 mm/s²；
4. 车身净空不小于 300 mm，等价的同参考点间距不小于 1250 mm；
5. Port、MERGE、CurveGroup 容量均不超过 1；
6. 取货和放货服务时间均为 8 s；
7. 输出任务结果、0.2 s 逐步轨迹、算法指标和硬约束审计结果；
8. 结果数值只能来自正式程序运行，不用估计值补表。

## 2. 数据处理

### 2.1 输入

- 附件 1：Node；

## 3. 数学模型

将第一问建模为带位置、优先级和交通资源约束的静态多车取送路径问题（PDVRP-RC）。

主要决策为：

- `x[j,k]`：任务 j 是否分配给 OHT k；
- `y[i,j,k]`：OHT k 是否在任务 i 后紧接执行任务 j；
- 每个空载段和载货段的有向 Link 路径；
- Port、MERGE 和 CurveGroup 的通过顺序；
- 每个 0.2 s 控制步的速度与加速度。

官方目标为：

\[
\min \bar T=\frac{1}{32}\sum_{j=1}^{32}(C_j-r_j).
\]

优先级只用于同成本方案的任务排序和冲突仲裁，不替代官方目标。

## 4. 求解架构

### 4.1 基准方案

任务按优先级降序、CommandID 升序排列，依次追加给预计最早完成取送的车辆；路径采用位置感知的自由流最短时间路径。

### 4.2 改进方案

采用仿真前代理成本驱动的 ALNS：

1. 以全局最小增量插入构造初解；
2. 使用随机移除、最差贡献移除和相关任务移除；
3. 使用最小增量与 regret 插入修复；
4. 用模拟退火准则接受候选；
5. 代理目标包含总完成时间、轻量优先级迟延、Makespan 和空载距离；
6. 对最终候选运行同一高保真物理仿真；
7. 基准和改进方案均零违规时，按真实平均任务执行时间选择最终方案。

### 4.3 位置感知路径

车辆当前位置和 Port 均表示为 `(LinkID, offset)`。从当前位置到目标 Port 的距离由“当前 Link 剩余段 + 中间完整 Link + 目标 Link 前缀”组成；目标在同一 Link 后方时必须沿有向网络绕行，不能掉头。正常任务路径禁止进入 TERMINAL。

## 5. 物理仿真

采用 `dt=0.2 s` 的同步仿真：

1. 处理服务完成与任务切换；
2. 对即将到达的 MERGE/CurveGroup 进行确定性仲裁；
3. 根据 Link 限速、目标 Port、前车、下游入口和资源停止线计算安全速度上界；
4. 在加减速度边界内更新速度和位置；
5. 跨 Link 时延续跟驰关系，不允许逆行或超车；
6. 到达 Port 后占用 8 s，服务车阻断后车；
7. CurveGroup 从车头进入至车尾完全离开后释放；
8. MERGE 在下游安全间距形成后释放；
9. 完成全部任务后停止，并保留完整 20 车轨迹。

空闲车辆仍作为轨道实体运行。为避免任务完成后永久停在 Port 阻塞交通，空闲车辆沿合法非 TERMINAL Link 低优先级巡航，并在所有载货或执行中车辆前让行。

## 6. 验证与审计

### 6.1 数据级

- 131 Node、152 Link、36 Port、20 OHT、32 Task；
- 33 CurveGroup、21 MERGE；
- P17 修订值唯一生效；
- 所有 Port/OHT offset 位于所在 Link 内。

### 6.2 轨迹级

- 每个仿真步恰有 20 辆车记录；
- 位置始终位于 `[0, LinkLength]`；
- 速度位于 `[0, LinkVelocity]`；
- 加速度位于 `[-3000,2000]`；
- 同 Link 前后车辆同参考点间距不小于 1250 mm；
- 每个互斥资源任一时刻最多一个 owner；
- 服务时间、任务状态顺序和路径连续性正确。

### 6.3 结果级

- 32 个 CommandID 恰好各出现一次；
- 时间字段单调；
- `TransferTime = TransferCompletedTime - InstallTime`；
- 距离由实际 Link 片段重新累计；
- 指标由任务事件日志自动聚合；
- 保存 Excel 后重新读取并核对表头、行数和必填字段。
