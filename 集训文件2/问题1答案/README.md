# 问题1答案文件说明

本文件夹汇总第一问全部需要使用的结果、说明文档和复现代码。原始附件未重复复制。

## 正式提交结果

- `问题1_结果.xlsx`：附件 9 格式的正式结果，包含任务结果、OHT 逐步运行记录和算法指标。
- `问题1_任务结果.csv`：32 项任务的车辆、时间、距离和路径明细。
- `问题1_OHT逐步运行记录.csv`：20 辆 OHT、0.2 s 步长的完整轨迹。
- `问题1_算法评价指标.csv`：第一问官方评价指标。

## 方案与验证证据

- `问题1_方案.json`：三套方案比较、最终车辆任务链和配置参数。
- `问题1_约束审计.json`：数据、运动学、间距和轨迹完整性审计结果。
- `问题1_结果说明.md`：结果摘要与复现说明。
- `第一问_建模与求解报告.md`：数学模型、算法和结果分析。
- `第一问详细实施计划.md`：第一问完整实施计划。

## 复现代码

- `q1_solver.py`：第一问求解、仿真和结果导出程序。
- `verify_q1.py`：正式结果独立复核程序。

程序运行时仍需从上一级项目目录读取题目原始附件 1—9，因此建议保留当前目录结构。
