# 集训模拟题（机理分析与仿真类）

## 北极边缘冰区海冰演化与船舶安全航行建模

> 本文档由题目 PDF《研究生集训模型1（订正后版本）——北极边缘冰区海冰演化与船舶安全航行建模.pdf》整理，

## 一、背景

### 1.1 北极航运的机遇与隐忧

北极航线商业价值凸显。据估算，北极东北航线相比传统苏伊士运河航线可缩短航程约 40%，大幅降低燃料消耗与航行时间。2025 年北极航线实现跨越式发展：航次增至 103 次，全年总货运量达 320 万吨。LNG 船、杂货船、集装箱船已将北极航线纳入常规运营。

北极航运增长背后安全风险持续加剧。文献[1]统计显示，2005–2024 年北极东北航线共发生 170 起海事事故，其中 65.4% 发生在距最近搜救基地 200 公里以上的偏远水域；事故数从 2005–2014 年的 18 起增至 2015–2024 年的 40 起，增长 122%。

### 1.2 核心挑战

北极商船航行的核心矛盾：**冰情变化快，但观测稀疏、预报不准、决策滞后**。三个环环相扣的难题：

1. 海冰数值模式关键参数在极地缺乏实测约束，取值差异可达数倍，模式输出不可靠；
2. 有限观测难以约束全海域初始状态，从稀疏数据反演全场本质上是病态问题；
3. 高纬度通信受限、船载算力有限，冰情预报难以及时转化为动态航线决策。

## 二、物理模型

### 2.1 海冰动量方程

海冰运动控制方程为动量守恒方程（向量形式）：

ρᵢhᵢ dU/dt = −ρᵢhᵢf(k×U) + ∇·σ + τ_wi + τ_a　　（1）

左边为惯性力，ρᵢ 为冰密度，hᵢ 为冰厚，U=(U,V) 为海冰流速。

- **科里奥利力** −ρᵢhᵢf(k×U)：北半球使运动物体持续右偏，分量形式为 (ρᵢhᵢfV, −ρᵢhᵢfU)；
- **流变内力** ∇·σ：冰盖内应力不均匀产生合力，σ 为内应力张量；
- **冰水拖曳力** τ_wi：方向与冰和水的相对速度 u−U 一致；
- **风应力** τ_a：风吹冰面拖拽，方向与风向一致。

展开为 x（东向）、y（北向）两个分量：

x 方向：ρᵢhᵢ(∂U/∂t + U∂U/∂x + V∂U/∂y) = ρᵢhᵢfV + ∂σ_xx/∂x + ∂σ_xy/∂y + τ_wi,x + τ_a,x　　（2）

y 方向：ρᵢhᵢ(∂V/∂t + U∂V/∂x + V∂V/∂y) = −ρᵢhᵢfU + ∂σ_yx/∂x + ∂σ_yy/∂y + τ_wi,y + τ_a,y　　（3）

冰水拖曳力分量：

τ_wi,x = ρ_w C_d √[(u−U)² + (v−V)²] (u−U)

τ_wi,y = ρ_w C_d √[(u−U)² + (v−V)²] (v−V)

其中 ρ_w 为海水密度，C_d 为冰水拖曳系数。

### 2.2 黏塑性模型（VP 本构关系）

内应力张量 σ 的分量公式：

σ_ij = 2η ε̇_ij + (ζ − η)(ε̇_kk)δ_ij − P/2 δ_ij，　i,j = x,y　　（4）

- ε̇_xx = ∂U/∂x，ε̇_yy = ∂V/∂y，ε̇_xy = (∂U/∂y + ∂V/∂x)/2，ε̇_kk = ε̇_xx + ε̇_yy；
- δ_ij 为 Kronecker delta；η 剪切黏度；ζ 体积黏度；P 冰强度；
- 剪切黏度 η = P/(2Δ)，体积黏度 ζ = P/(2Δ)，Δ 为应变率不变量：

Δ = √[(ε̇_xx² + ε̇_yy²)(1 + e⁻²) + 4e⁻²ε̇_xy² + 2ε̇_xx ε̇_yy(1 − e⁻²)]

P = P\* hᵢ exp[−20(1 − A)]

P\* 为抗压强度系数，A = hᵢ/hᵢ0 为冰密集度。

### 2.3 海冰厚度守恒方程

在几天内的冰情演化中，热力学对冰厚改变仅厘米级，远小于动力学平流输运的分米级变化，可忽略热力学源项，冰厚守恒退化为纯平流方程：

∂hᵢ/∂t + ∂(hᵢU)/∂x + ∂(hᵢV)/∂y = 0　　（5）

### 2.4 浅水方程（SWE）

海域平均水深 30 m，水平尺度 20 km，满足浅水条件。

（1）海水高度方程（质量守恒）：

∂η/∂t + h_w(∂u/∂x + ∂v/∂y) = 0　　（6）

（2）海水动量方程：

∂u/∂t + (u·∇)u = −g∇η − f(k×u) − τ_wi/(ρ_w h_w)　　（7）

分量形式：

x：∂u/∂t + u∂u/∂x + v∂u/∂y = −g∂η/∂x + fv − τ_wi,x/(ρ_w h_w)　　（8）

y：∂v/∂t + u∂v/∂x + v∂v/∂y = −g∂η/∂y − fu − τ_wi,y/(ρ_w h_w)　　（9）

冰通过 τ_wi 获得水的动量，水通过 −τ_wi 失去动量，形成冰水耦合闭环。

## 三、建模任务

研究矩形海域 [0, L_x]×[0, L_y]，L_x = 20000 m，L_y = 10000 m。空间离散 M_x×M_y = 200×100 个均匀网格，Δx = Δy = 100 m。时间区间 [0, T]，T = 86400 s（24 h），Δt = 300 s，总时间步数 N_t = 288。均匀水深 h_w = 30 m。

**初始条件（t = 0）：**

- 海面高度 η(x,y,0) = 0；
- 海水流速 u(x,y,0) = 0，v(x,y,0) = 0；
- 海冰流速 U(x,y,0) = 0，V(x,y,0) = 0；
- 初始冰厚场：

hᵢ(x,y,0) = 0.5 + 0.3 sin(πx/L_x) cos(πy/L_y)　　（10）

**边界条件（四周边界）：**

- 海冰固壁无滑移：U = 0，V = 0；
- 海水浅水波固壁（法向速度为零、切向自由）：x = 0 与 x = L_x 处 u = 0；y = 0 与 y = L_y 处 v = 0；
- 冰厚零法向通量（Neumann）：∂hᵢ/∂n = 0。

### 问题一：海冰动量方程简化

海冰动量方程（1）直接数值模拟成本较高。取特征水平长度 L₀ = 20000 m、特征流速 U₀ = 0.5 m/s、特征冰厚 hᵢ0 = 1 m、特征时间 T₀ = L₀/U₀，分别计算惯性力、科里奥利力、冰水拖曳力、流变内力、风应力五项的特征量级，对比分析后判定忽略量级远小于其他项的力，获得方程（2）（3）的简化形式。

要求：讨论简化方案在碎冰区（hᵢ→0）和厚冰区（hᵢ≫1 m）两种极端冰情下是否成立，以及什么条件下简化失效。

### 问题二：冰水耦合数值求解（24 h 全域正演）

取问题一简化后的海冰动量方程及附录参数（如 C_d = 0.005 等），选取合适数值模拟算法求解。

要求给出：

1. t = 24 h 的全域冰厚场和冰速场（等值线图或矢量图）；
2. 区域平均冰厚和全域最大冰速（精确到 6 位小数）；
3. t = 0、6、12、18、24 h 的冰厚分布图；
4. 海域中心点（10000, 5000）处冰厚随时间变化曲线；
5. 分析冰速场空间分布规律（最大冰速出现区域、与冰厚梯度和风应力方向的关系等）。

### 问题三：关键参数反演

关键参数缺乏实测约束，取值不确定：

- 冰水拖曳系数 C_d：范围 [0.002, 0.015]，通常 0.005；
- 风应力缩放系数 α（τ_a = α·(0.12, 0.04) N/m²）：范围 [0.5, 1.5]，通常 1。

利用 6 个位置 t = 24 h 的冰速观测数据（表 1）优化确定上述两参数。**至少采用两种优化方法**，对比参数识别精度、计算效率、初值敏感性等多维度差异。

### 问题四：初始冰厚场反演 + 48 h 预报

背景场由（10）给出，但需依据有限观测校正。提供 6 个固定位置在 t = 6 h、12 h、24 h 共 18 组冰速观测（表 2，其中 24 h 数据同表 1）。以初始冰厚场 hᵢ(x,y,0) 为控制变量，以简化动量方程和冰厚平流方程为物理约束，极小化模式预报冰速与观测冰速偏差，反演最优初始冰厚场；再以该优化场为初值预测 t = 48 h 的冰速场和冰厚场，绘制空间分布示意图。

### 问题五：动态航线优化（72 h 预报 + 全局最优航线）

基于问题三反演参数对 (C_d\*, α\*) 及问题四反演初始场，运行正演模式生成 t ∈ [24, 72] h 逐小时冰密集度预测场 A(x,y,t)，绘制三张典型时刻冰密集度场。

LNG 船 t = 24 h 从起点 S(1000, 5000) m 出发，须在 t = 72 h 前抵达终点 E(19000, 5000) m：

- 最大航速 V_max = 15 节（1 节 = 0.5144 m/s）；
- 冰密集度 A > 0.6 区域禁止通行；
- 可通行区域内航速：V_s(t) = V_max·(1 − A(x(t),y(t),t))　　（11）
- 燃料消耗率：q(t) = q₀ + q₁V_s²(t)　　（12），q₀ = 0.5 吨/小时，q₁ = 0.005 吨·h/m²。

通过优化建模设计离散化策略与求解算法，给出全局最优航线、总航行时间和总燃料消耗，绘制 LNG 航行几何路径并标记关键航路点坐标。
